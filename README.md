# Скільки коштує дизайн

Опитувальник на рівень дизайнера (новачок / мідл / сеньйор) і розрахунок вартості
роботи за українським фриланс-ринком: логотип, айдентика за кількістю носіїв,
багатосторінкова продукція, упаковка.

Результат показано вилкою у гривнях і доларах. Курс підтягується з
[API Національного банку](https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange?valcode=usd&json).

Усі ціни та питання лежать у `data.js` — їх можна правити без зміни решти коду.
Звідки взяті цифри — видно на самому сайті у блоці «Звідки цифри».

Розрахунок відбувається у браузері, відповіді нікуди не надсилаються.
